# Email Reply

When asked to handle, reply to, or draft a response to an email:

1. Read the email thread in `emails/` to understand the conversation and what's being asked
2. Check `brain/` for notes about the person or topic — look in `brain/people/` and `brain/projects/`
3. Check both Google Calendars ("CEMS-Business" and "CEMS-Private") for Andrew's availability in the relevant time window
4. Check Todoist ("CEMS Showcase" project) for any existing tasks related to this person or thread
5. Draft a reply that:
   - Directly addresses scheduling requests with concrete times based on actual availability
   - Proposes alternatives if the requested times don't work
   - References relevant context from the brain notes (shared interests, past conversations, open promises)
   - Keeps the tone professional but warm — like someone who actually knows this person
6. Create the draft in Gmail (to the sender's email address, with the original subject line)
7. If a meeting was agreed on, create it on the "CEMS-Business" Google Calendar with both participants
8. Add a 30-minute "Meeting prep" blocker on the "CEMS-Business" calendar right before the meeting
9. If there are follow-up actions (intros to make, docs to send, things to prepare), create tasks in Todoist ("CEMS Showcase" project) with due dates. Include a link to the Gmail draft in the task description.
