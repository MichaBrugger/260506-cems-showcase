# Evening Planner

Review everything and plan tomorrow. Designed to run every evening.

## Steps

1. Read all email threads in `emails/` — identify which need replies, which are FYI, which are urgent
2. Check both Google Calendars for tomorrow's schedule:
   - **"CEMS-Business"** — work meetings, deadlines
   - **"CEMS-Private"** — personal commitments that block time
   - Note back-to-back meetings, gaps, conflicts between work and personal
3. Read `brain/people/` for context on anyone you're meeting or emailing tomorrow
4. Read `brain/projects/` for anything related to tomorrow's meetings or active threads
5. Check Todoist ("CEMS Showcase" project) for outstanding tasks — what's due tomorrow, what's overdue
6. Produce `daily-plan.md` with:
   - **Schedule:** Tomorrow's events (both calendars) with prep notes and relevant context
   - **Email drafts:** Replies for threads that need a response
   - **Tasks:** Prioritized list — what to tackle, what can wait
   - **Flags:** Anything that needs attention (conflicts, overdue items, personal/work overlap)
   - **Suggestions:** Time optimization, prep reminders, smart routing between personal and work
